# VLS_HELIOS-

Repositorio con los elementos utilizados en la simulación LiDAR para la tesis:

**Simulación LiDAR a partir de nube de puntos de *Nothofagus alessandrii* de la Estación Experimental Frutillar, X Región de Los Lagos, Chile.**

## Contenido

Todo el material ejecutable (escena HELIOS++, survey Ruil_MLS, vox, DEM, scripts de métricas y datos del rodal) está en la carpeta:

**[`HELIOS++/`](HELIOS%2B%2B/)**

## Inicio rápido

```bash
git clone https://github.com/patricioerazo-create/VLS_HELIOS-.git
cd VLS_HELIOS-
cd "HELIOS++"
```

Metodología completa: [`HELIOS++/docs/METODOLOGIA_SIMULACION_Ruil_MLS.md`](HELIOS%2B%2B/docs/METODOLOGIA_SIMULACION_Ruil_MLS.md)
